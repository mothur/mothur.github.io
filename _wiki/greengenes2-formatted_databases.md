The [biocore group](https://github.com/biocore/greengenes2/) has revived the greengenes database. A description of their approach was published in [Nature Biotechnology](https://www.nature.com/articles/s41587-023-01845-1). If you use these files, you should cite McDonald et al. I have modified the versions made available on the greengenes2 ftp server. The most notable difference is that I removed the species level names since most of the genera only have one species name. In my opinion, this would give an overly specific sense of the classification of your sequences since there is insufficient diversity within each species.

* [September 2024 release](https://ftp.microbio.me/greengenes_release/2024.09/). Please see the [mothur blog post](/blog/2026/greengenes2_2024_09/) for a reproducible workflow of how I generated the mothur-compatible version of the database. This is the same as the README file found within [our download available here](https://mothur.s3.us-east-2.amazonaws.com/wiki/greengenes2_2024_09.wo_sp.tgz)
